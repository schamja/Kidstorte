02 · Datei-Verbindungen

nodes.py – das Herzstück

nodes.py ├── importiert config.py → liest Prompts aus YAML ├── importiert state.py → liest/schreibt AgentState ├── importiert error_handler.py → Fehler abfangen ├── nutzt OpenAI API → GPT-4o-mini (Text + Vision) ├── nutzt OpenAI API → gpt-image-1 (Bilder generieren) ├── nutzt HuggingFace API → FLUX/SDXL (Backup-Bilder) └── nutzt ChromaDB → RAG Wissensbasis durchsuchen
Hot-Reload: config.py prüft ob die YAML geändert wurde → Prompts wirken sofort ohne Neustart

04 · RAG

Was ist RAG?

❌ Ohne RAG
Kunde: "Was kostet Schoko?"
KI: erfindet einen Preis
    → halluziniert ❌
✅ Mit RAG
Kunde: "Was kostet Schoko?"
ChromaDB: findet "ab 35€"
KI: antwortet korrekt ✅
Bewertung: Mittelstark – gut für Preise und FAQ · nur bei intent = "price" oder "info" aktiv · nur .md Dateien unterstützt

06 · Multimodales RAG

Bilder verstehen und generieren

1
_scan_reference_images()Lädt alle Bilder aus dem Bilder/ Ordner als base64
2
_find_best_reference()GPT-4o-mini Vision sieht alle Bilder, vergleicht mit Kundenwunsch → wählt bestes Bild + beschreibt es auf Englisch
3
generate_single_image()gpt-image-1 oder FLUX bekommt Beschreibung + Kundenwünsche → generiert passendes Bild
Personennamen (Elsa, Ronaldo)? → direkt HuggingFace FLUX · kein Copyright-Filter
07 · Prompt-System

5 Stärken des Prompt-Systems

Hot-Reload

YAML-Änderungen wirken sofort – kein Server-Neustart nötig

50% Kosten gespart

Classify + Extract in einem einzigen API-Call kombiniert

TODO-System

pending → asked → answered – keine Frage wird zweimal gestellt

Halluzinations-Schutz

"ERFINDE NIEMALS Werte!" · Namen buchstabengenau (Aron ≠ Aaron)

Guardrail

LLM-basiert · im Zweifel immer OK · kein echter Kunde wird versehentlich blockiert
